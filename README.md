# Manuel Alayón · Portfolio

Portfolio interactivo de Manuel Alayón Pimienta, social media manager especializado en estrategia digital, creación de contenido y comunidades. La interfaz se inspira en iOS.

[Visitar la web](https://dnsue01.github.io/pepperPortfolio/)

## En el repositorio

Este repositorio contiene la exportación estática de Next.js. `index.html` es la entrada y `_next/` contiene los recursos compilados.
